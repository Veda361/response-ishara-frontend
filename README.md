# response-ishara-frontend

Frontend application for Ishara Response system, built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Routing:** [React Router](https://reactrouter.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Charts:** [Recharts](https://recharts.org/)
- **Linting:** [Oxlint](https://oxc.rs/)

## 📋 Prerequisites

- Node.js (v18+ recommended)
- npm / yarn / pnpm

## ⚙️ Environment Configuration

Copy the example environment file and configure the backend URL:

```bash
cp .env.example .env
```

Ensure `VITE_API_URL` points to your backend service:
```env
VITE_API_URL=https://reposnse-ishaara.onrender.com
```

## 🛠️ Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

### 3. Build for Production

```bash
npm run build
```

### 4. Preview Production Build

```bash
npm run preview
```

### 5. Code Quality & Linting

```bash
npm run lint
```
